# Data and code for Chan et al., A waming climate increases suitability for vector-borne disease transmission on Inuinnait Nuna, the Canadian Arctic.

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE) [![DOI](https://img.shields.io/badge/DOI-pending-lightgrey.svg)](#citation)

Authors: Lilian T.Y. Chan, Marta Shocket, Shauna Dworatzek, Danielle S.J. Nowosad, Jason Laurich, Thomas Mcilwraith, Beau Taptuna, Hannah Zikalala, Sarah J Adamowicz and Joey R. Bernhardt

Description: In this study, we developed a temperature-dependent, trait-based mechanistic model to quantify the thermal suitability of transmission for Setaria yehi, a mosquito-borne nematode parasite of caribou in the Canadian Arctic. We synthesized published laboratory data on mosquito and parasite thermal traits, fitted temperature performance curves (TPCs) in a Bayesian framework, and integrated these traits into a transmission suitability model. We then projected transmission suitability under historical and future climate scenarios to assess how Arctic warming may alter the duration and geographic extent of disease transmission. 

Raw trait data are located in the repository's [data-raw/](https://github.com/BernhardtLab/Arctic-VBD/tree/master/data-raw) folder. The workflow for the analysis includes 16 scripts, meant to be run in order. Scripts are located in the repository's [R-scripts/](https://github.com/BernhardtLab/Arctic-VBD/tree/master/R-scripts) folder and figures and tables produced by each script are stored in the [figures/](https://github.com/BernhardtLab/Arctic-VBD/tree/master/figures) folder.


## Scripts
**00_Conceptual_figure.R**: This script created the conceptual figures for the manuscript, and produces figures 1 and 2.

**00_Functions.R**: This script contains the functions to load for use in other scripts.

**00_TPC_models.R**: This script provides the JAGS models for fitting TPCs.

**01_Data_Processing.R**: This script cleans and processes raw trait data, then export each trait as a separate CSV file which are stored in the [data-processed/](https://github.com/BernhardtLab/Arctic-VBD/tree/master/data-processed) folder.

**Scripts 02 - 09**: Each script fits TPCs for a trait, with the naming convention: "0X_trait_fits_{trait name}.R". Model outputs were saved under [data-processed/{trait_name}](https://github.com/BernhardtLab/Arctic-VBD/tree/master/data-processed), which are used as an input for scripts 11-12. Individual TPC fit plots were saved in the [figures/TPC-fits/](https://github.com/BernhardtLab/Arctic-VBD/tree/master/figures/TPC-fits) folder.

**10_latitudinal_analysis.R**: This script tests the relationship between latitude and TPC parameters for all traits except vector competence.

**11_suitability_calculation.R**: This script parameterizes the suitability model and conducts sensitivity analysis.

**12_plot_trait_TPCs.R**: This script creates plots for TPCs and summary tables for TPC parameters. This script produces main text figure 3, supplementary figures S1-6, as well as supplementary tablesS5-6.

**13_mapping_median.ipynb**: This script creates spatiotemporal maps by quantifying days per year exceeding suitability threshold using posterior median predictions (50% quantile). This script also examines temporal trends across three focal regions: Cambridge Bay, Kugluktuk, and Yellowknife, analyzing time series of suitable transmission days, first/last day of transmission season, and mean summer temperature under current and future climate scenario. 

**14_mapping_lowerCI.ipynb**: Same as script 13, except using lower credibility bounds (2.5% quantile) of the posterior distribution.

**15_mapping_upperCI.ipynb**: Same as script 13, except using upper credibility bounds (97.5% quantile) of the posterior distribution.

**16_Kitikmeot_summer_temp.R**": This script calculated the mean air temperature in Cambridge Bay and Kugluktuk over the sampling period in 2025.


## Data

The [data/raw-data/](https://github.com/BernhardtLab/Arctic-VBD/tree/master/data-raw) folder contains two directories:

-   **[trait-data](https://github.com/BernhardtLab/Arctic-VBD/tree/master/data-raw/trait-data)**: Published estimates of thermal traits. Each file contains data from each source. This is the primary input for script 01.

-   **[temperature-data](https://github.com/BernhardtLab/Arctic-VBD/tree/master/data-raw/temperature-data)**: Daily temperature from the weather station in Kugluktuk and Cambridge Bay. Each file contains data from each year and each location. File are named: en_climate_daily_NU_[ID]_[year]_P1D.csv, where ID = 2300903 is Kugluktuk and 2400601 is Cambridge Bay. Data from 2025 are the input for script 16.



The [data/processed-data/](https://github.com/BernhardtLab/Arctic-VBD/tree/main/data/processed-data) folder contains the following files/folders generated by the analysis scripts:

-   **TraitData_[trait].csv**: cleaned data for each trait, generated by script 01. They are required inputs for scripts 02–09.

-   **mapping**(https://github.com/BernhardtLab/Arctic-VBD/tree/master/data-processed/mapping): Number of suitable days at each time period, generated by scripts 13-15.


It also contains a folder for each trait and [suitability](https://github.com/BernhardtLab/Arctic-VBD/tree/main/data/processed-data/suitability), each contains:

- **params.fullpost.csv**: Full posterior distributions for TPC parameters (T0, Tm, q) and Tbreadth. Contains 12,000 rows (MCMC iterations).
- **params.summary.csv**: Summary statistics of TPC parameters.
- **prediction.summary.csv**: Posterior summary of TPC predictions.

## Archive

The [archive/](https://github.com/BernhardtLab/Arctic-VBD/tree/master/archive) folder contains earlier versions of scripts, data, and figures that were produced during the development of the analysis but are not part of the final manuscript workflow. This includes previous R scripts, intermediate data files, and older figure outputs. These files are retained for reference but are not required to reproduce the results in the paper.

## Reproducibility

To reproduce the exact results from the manuscript, package versions matter. To check your current package environment, run the following in R:

``` r
sessionInfo()
```

If you encounter differences in results, please check your package versions against those listed in `sessionInfo()` output.
